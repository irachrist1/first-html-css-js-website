# first-html-css-js-website

First HTML/CSS/JS website — early web fundamentals exercise with Apple-inspired layout experiments.

## The problem

You are learning how HTML structure, CSS layout, and basic JS fit together for the first time.

## What it does

Static multi-asset page with images and components — a first complete site before frameworks.

## Install

```bash
git clone https://github.com/irachrist1/first-html-css-js-website.git && cd first-html-css-js-website
open index.html
```

## How it works

- **Structure + style + behavior.** Separate concerns across HTML, CSS, and JS files — the baseline web stack.
- **Asset-heavy layout.** Images and components folder — practice linking resources correctly.
- **First project archive.** Preserved for history — superseded by later React/Next.js work.
